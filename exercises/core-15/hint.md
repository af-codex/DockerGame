A multi-stage build uses multiple `FROM` instructions. Each `FROM` starts a new build stage. You can name stages and copy artifacts from one stage to another. Python's `compileall` command writes a `.pyc` bytecode file beside the source when you pass `-b`.

Here is the basic structure:

```Dockerfile
# --- Build Stage ---
# Compile with the same Python version used in the runtime image
FROM python:3.12 AS builder
WORKDIR /src
COPY app/app.py .
RUN python -m compileall -b -o 2 app.py


# --- Final Stage ---
FROM python:3.12-alpine
WORKDIR /app
COPY --from=builder /src/app.pyc .
EXPOSE 8080
CMD ["python", "-B", "app.pyc"]
```
The builder and runtime use the same Python version so the generated bytecode is compatible. The Alpine runtime image is much smaller than the full builder image.
